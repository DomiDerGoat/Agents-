# Agents-

## Plugins

- `plugins/nateherk-design/`: Skill **scroll-craft** von Nate Herk (MIT, Quelle: https://github.com/nateherkai/scroll-craft, v0.3.1)

Der Skill ist über `.claude/skills/scroll-craft` (Symlink) für Claude Code verfügbar und wird
beim Start einer Session automatisch geladen. Aufruf: `/scroll-craft`.

Lokal lässt sich das Repo auch als Marketplace nutzen:
```
/plugin marketplace add DomiDerGoat/Agents-
/plugin install nateherk-design@nateherk
```
